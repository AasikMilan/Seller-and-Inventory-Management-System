The e-commerce company sells products supplied by multiple sellers. The system should maintain seller details, track products supplied by each seller, and monitor inventory levels to ensure product availability. Students will create a Seller and Inventory Management Module connected with the existing Product database.
1. Create Seller and Inventory tables.
2. Establish relationships between sellers, products, and stock.
3. Maintain seller product information.
4. Track available and unavailable products.
5. Generate inventory status reports.
